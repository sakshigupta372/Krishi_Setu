# ⚡ Quick Start - Authentication & New Features

## 🚀 5-Minute Setup

### Step 1: Start Servers (2 min)

**Terminal 1:**
```bash
cd backend
npm start
```

**Terminal 2:**
```bash
cd dashboard
npm start
```

### Step 2: Open Browser (1 min)
```
http://localhost:3001
```

### Step 3: Create Account (2 min)

1. Click **"Sign up now"**
2. Fill the form:
   - Name: Your Name
   - Email: your@email.com
   - Password: (min 6 characters)
   - Confirm password
   - Add phone, farm size, location
3. Click **"Create Account"**
4. **Auto-logged in!** 🎉

## 🐛 Quick Fixes

### Can't login?
→ Signup first! No default accounts

### Dashboard blank?
→ Hard refresh: **Ctrl+Shift+R**

### Backend errors?
→ Restart: **Ctrl+C** then **npm start**

### Animations laggy?
→ Close other browser tabs
