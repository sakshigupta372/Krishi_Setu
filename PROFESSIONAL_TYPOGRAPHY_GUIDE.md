## 🐛 Troubleshooting

### Fonts not changing?
```bash
# Hard refresh
Ctrl + Shift + R

# Or clear cache completely
Ctrl + Shift + Delete → Clear all
```

### Still looks the same?
```bash
# Check if Google Fonts loaded
F12 → Network → Filter: "fonts.googleapis"
Should see Inter font loaded
```

### Text looks blurry?
```
1. Enable ClearType (Windows)
2. Check display scaling (100% recommended)
3. Update browser to latest version
4. Enable font smoothing in browser
```
